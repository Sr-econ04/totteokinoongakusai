# さんだとっておきの音楽祭 スマホペンライト

**さんだとっておきの音楽祭**で使うための、スマートフォン版ペンライトです。
スマホの画面が 9 色に光り、ペンライトの代わりになります。

アプリのインストールは不要です。ブラウザでページを開くだけで使えます。
ふりがなや大きな文字、読み上げ機能への対応など、だれもが使いやすいように作っています。

> [!NOTE]
> スマートフォン専用です。パソコンで開くと、画面の配置が大きく見えることがあります。

---

## 特長

- **9 色から選べる** … 赤・オレンジ・黄色・黄緑・緑・水色・青・紫・ピンク
- **2 つの光り方** … 「ずっと点灯」と「カラーチェンジ」
- **画面が消えない** … 光っている間はスマホがスリープしません（対応端末のみ）
- **ユニバーサルデザイン** … ふりがな付き、大きな文字とボタン、読み上げ機能に対応
- **ライトモード / ダークモード** … スマホの設定に合わせて自動で切り替わります
- **選んだ色を覚える** … 次に開いたときも同じ設定で始められます

---

## 使い方

1. **光り方を選ぶ**
   - **ずっと点灯** … 選んだ 1 色で光り続けます
   - **カラーチェンジ** … 選んだ色が順番に変わります
2. **色を選ぶ**
   - ずっと点灯：1 色を選びます
   - カラーチェンジ：1〜9 色を選びます。押した順番に光ります（もう一度押すとはずれます）
3. **「点灯する」を押す**
4. **戻るとき** は画面を押して、出てきた「戻る」ボタンを押します

> [!TIP]
> 画面の明るさは、スマホの設定で**最大**にしてください。
> Web ページからは画面の明るさを変えられないためです。

---

## 光り方の仕様

### ずっと点灯

選んだ 1 色のまま、明るさも変わらずに光り続けます。

### カラーチェンジ

色と色の間に黒をはさみ、なめらかに切り替わります。

```
 2秒点灯 → 1秒で黒へ → 1秒で次の色へ → 2秒点灯 → …
└──────── 1色あたり 4秒 ────────┘
```

| 選んだ色の数 | 動き |
| --- | --- |
| 1 色 | 2 秒点灯 → 黒へ → **同じ色**に戻る、をくり返す |
| 2〜9 色 | 選んだ順に光り、最後の色の次は最初の色に戻る |

- 暗くなる・明るくなる変化には、なめらかな加速・減速（ease-in-out）を使っています
- 明るさの変化は 4 秒に 1 回です。光の点滅で体調が悪くなるおそれのある速さ（1 秒に 3 回以上）より、十分ゆっくりにしています

## ユニバーサルデザインとアクセシビリティ

### 見やすさ

- 読みやすさを重視した書体 **BIZ UDPゴシック** を使っています
- すべての漢字に**ふりがな**を付けています
- 文字と背景の明るさの差を大きくし、文字の間と行の間にゆとりを持たせています
- ボタンは指で押しやすい大きさ（高さ 56px 以上）にしています

### 色が見分けにくい人への配慮

- 色の見本の下に、必ず**色の名前**を文字で書いています
- 選んだ色は、色だけでなく**太い枠**と **✓・番号**でも分かります
- 光っている間も、今の色の名前を画面の下に表示します

### 読み上げ機能（VoiceOver / TalkBack）への配慮

- ふりがなを二重に読まない工夫をしています（「色いろ」ではなく「色」と読みます）
- 画像や色の見本には、代わりの説明文（`alt` / `aria-label`）を付けています
- 「黄色を 2 番目に追加しました」「点灯しました」など、操作の結果を読み上げます
- 見出しは「手順 1、光り方」のように、手順の番号が分かる形で読み上げます
- 点灯中は点灯画面だけを操作できるようにし、「戻る」ボタンに自動でフォーカスします
- キーボードでは `Esc` キーでも戻れます
- 端末で「視差効果を減らす」を設定している場合は、ボタンの動きを控えめにします

## 動作環境

| 端末 | ブラウザ | 備考 |
| --- | --- | --- |
| iPhone | Safari（iOS 16.4 以降を推奨） | 全画面表示はできません。ホーム画面に追加して開くと画面いっぱいに近くなります |
| Android | Chrome | 全画面表示とスリープ防止に対応 |

### できないこと・注意点

- **画面の明るさは自動で上げられません。** Web ブラウザが明るさの変更を許可していないためです。
  自動で最大にするには、ネイティブアプリにするか、[Capacitor](https://capacitorjs.com/) などでアプリ化して明るさ変更のプラグインを使う必要があります。
- **スマホの「戻る」操作では、アプリの外に出てしまいます。** 戻るときは画面の「戻る」ボタンを使ってください。
- **古い端末では、光っている間に画面が消えることがあります。** スリープ防止（Screen Wake Lock API）に対応していない端末です。スマホの自動ロックの時間を長くしてください。
- **フォントの読み込みにはインターネット接続が必要です。** つながらないときは、端末に入っている日本語の書体で表示されます。

## 使っている技術

- HTML / CSS / JavaScript（ライブラリなし）
- [Screen Wake Lock API](https://developer.mozilla.org/ja/docs/Web/API/Screen_Wake_Lock_API) … 画面のスリープ防止
- [Fullscreen API](https://developer.mozilla.org/ja/docs/Web/API/Fullscreen_API) … 全画面表示
- `requestAnimationFrame` … 色のなめらかな変化
- `localStorage` … 選んだ色と光り方の保存
- [BIZ UDPGothic](https://fonts.google.com/specimen/BIZ+UDPGothic)（Google Fonts）
