# さんだとっておきの音楽祭 スマホペンライト

**さんだとっておきの音楽祭**で使うための、スマートフォン版ペンライトです。
スマホの画面が 9 色に光り、ペンライトの代わりになります。

アプリのインストールは不要です。ブラウザでページを開くだけで使えます。
「みんな違って みんないい」の気持ちで、障害のある人もない人も、だれもが同じように使えることを大切に作っています。

> [!NOTE]
> スマートフォン専用です。パソコンで開くと、画面の配置が大きく見えることがあります。

---

## 特長

- **9 色から選べる** … 赤・オレンジ・黄色・黄緑・緑・水色・青・紫・ピンク。画面で見たときの明るさがそろうように調整しています
- **2 つの光り方** … 「ずっと点灯」と「カラーチェンジ」
- **光ったまま色を変えられる** … 点灯中に、好きな色やカラーチェンジの順番をその場で選べます
- **電波がなくても使える** … 一度開けば、会場で電波が弱くても動きます（オフライン対応）
- **ホーム画面に追加できる** … アプリのように画面いっぱいで起動できます
- **画面が消えない** … 光っている間はスマホがスリープしません（対応端末のみ）
- **ユニバーサルデザイン** … ふりがな付き、大きな文字とボタン、読み上げ機能・キーボード操作に対応
- **ライトモード / ダークモード** … 設定画面はスマホの設定に合わせて自動で切り替わります
- **選んだ色を覚える** … 次に開いたときも同じ設定で始められます

## 使い方

### 点灯するまで

1. **光り方を選ぶ**
   - **ずっと点灯** … 選んだ 1 色で光り続けます
   - **カラーチェンジ** … 選んだ色が順番に変わります
2. **色を選ぶ**
   - ずっと点灯：1 色を選びます
   - カラーチェンジ：1〜9 色を選びます。押した順番に光ります（もう一度押すとはずれます）
3. **「点灯する」を押す**
   - 色が 1 つも選ばれていないときは押せません。ボタンの下に「色を 1 つ以上選んでください」と出ます

### 光っている間の操作

| 操作 | できること |
| --- | --- |
| 画面の**下半分**を押す | 色を選ぶパネルが出る |
| 画面の**上半分**を押す | 画面の上に「色の名前」「色を選ぶ」「戻る」が出る（8 秒で消えます） |
| 「色を選ぶ」ボタン | 色を選ぶパネルが出る（画面の場所を押すのが難しい人・読み上げ機能を使う人向け） |
| 「戻る」ボタン | 設定画面に戻る |
| スマホの「戻る」操作 | 設定画面に戻る（Android の戻るボタン・戻るスワイプ） |

### 色を選ぶパネル

パネルの上で「ずっと点灯」と「カラーチェンジ」を切り替えられます。今の光り方は黒く表示されます。

- **ずっと点灯** … 色を押すと、すぐその色に変わります。次に自分で選ぶまで、その色のままです
- **カラーチェンジ** … 押した順に ①②③… と番号が付き、その順番で光ります
  - 押した色はすぐに光るので、確かめながら選べます
  - 番号の付いた色をもう一度押すと、はずれます
  - 「9 色すべて」「全部はずす」「決定」ボタンがあります
  - 色を全部はずしたままパネルを閉じると、それまで光っていた並びに戻ります
- パネルの外を押すか、30 秒さわらなければ閉じます

点灯中に選んだ色や順番は保存され、設定画面にも反映されます。

> [!TIP]
> 画面の明るさは、スマホの設定で**最大**にしてください。
> Web ページからは画面の明るさを変えられないためです。

## 光り方の仕様

### 点灯の始まり

どちらの光り方も、点灯した最初の 2 秒は、黒からふわっと光り始めます。

```
 黒 1秒 → 1秒で最初の色へ → （それぞれの光り方へ）
```

点灯中は、iPhone の Safari の画面の上下（時計のあたりとツールバーのあたり）も、光の色に合わせて塗っています。
もし実機で上下に色の合わない帯が残る場合は、`index.html` の `INTRO_RGB` を `[255,255,255]` にすると、始まりが白になります。

### ずっと点灯

選んだ 1 色のまま、明るさも変わらずに光り続けます。
色が変わらない間は描き直しの処理を止め、電池の減りを抑えています。

### カラーチェンジ

色と色の間に黒をはさみ、なめらかに切り替わります。

```
 2秒点灯 → 1秒で黒へ → 1秒で次の色へ → 2秒点灯 → …
└──────── 1色あたり 4秒 ────────┘
```

| 選んだ色の数 | 動き |
| --- | --- |
| 1 色 | 2 秒点灯 → 黒へ → **同じ色**に戻る、をくり返す |
| 2〜9 色 | 選んだ順に光り、最後の色の次は最初の色に戻る |

- 暗くなる・明るくなる変化には、なめらかな加速・減速（ease-in-out）を使っています
- 明るさの変化は 4 秒に 1 回です。光の点滅で体調が悪くなるおそれのある速さ（1 秒に 3 回以上）より、十分ゆっくりにしています

### 色の一覧

| 色 | ふりがな | カラーコード |
| --- | --- | --- |
| 🟥 赤 | あか | `#FF4233` |
| 🟧 オレンジ | ― | `#FF842F` |
| 🟨 黄色 | きいろ | `#F0D100` |
| 🟩 黄緑 | きみどり | `#9DED00` |
| 🟩 緑 | みどり | `#00C163` |
| 🟦 水色 | みずいろ | `#00D3F9` |
| 🟦 青 | あお | `#3A73FF` |
| 🟪 紫 | むらさき | `#A95AFF` |
| 🩷 ピンク | ― | `#FF5AAF` |

#### 色の決め方

- **明るさをそろえる** … 純粋な原色のままだと、画面では青・紫・緑が暗く沈み、黄色・黄緑がまぶしすぎます（明るさの差がおよそ 2 倍）。暗い色を明るく、明るすぎる色を少し抑えて、差を小さくしています
- **その色らしさを残す** … 画面の性質上、真っ青と真っ黄色を完全に同じ明るさにはできません。完全にそろえると青が薄くなったり、黄色がくすんだりするため、どの色も鮮やかに見える範囲でそろえています
- **隣どうしを見分けやすく** … 特に近い黄緑と緑は、黄緑を明るい若草色、緑を少し深い緑にして差を広げています

## ユニバーサルデザインとアクセシビリティ

### 見やすさ

- 読みやすさを重視した書体 **BIZ UDPゴシック** を使っています（ページに埋め込んであるので、電波がなくても同じ書体で表示されます）
- すべての漢字に**ふりがな**を付けています。ふりがなは小さくなりすぎないよう、最低 9px にしています
- 言葉の途中で改行されないようにしています
- 文字と背景の明るさの差を大きくし、文字の間と行の間にゆとりを持たせています
- ボタンは指で押しやすい大きさ（高さ 48px 以上）にしています
- 点灯中の色を選ぶパネルは、設定画面と同じ「白地に黒い文字・濃い枠」で、暗い会場でもボタンの境目が分かります
- 点灯中のボタンは「黒地に白い縁取り」で、どの色の光の上でもはっきり見えます
- 画面の小さいスマホや横向きでも、パネルがはみ出さないようにしています

### 色が見分けにくい人への配慮

- 色の見本の下に、必ず**色の名前**を文字で書いています
- 選んだ色は、色だけでなく**太い枠**と **✓・番号**でも分かります
- 光っている間も、今の色の名前と色の見本を画面の上に表示します

### 操作のしやすさ

- 色を変えるときは、「画面の下半分を押す」と「色を選ぶボタン」のどちらでもできます
- ボタンが消えるまでの時間（8 秒）や、パネルが閉じるまでの時間（30 秒）は長めにし、ゆっくり操作する人が途中で締め出されないようにしています。ボタンを操作している間は消えません
- 「戻る」ボタンは画面の上にあり、色を変えようとして下を押したときに、うっかり戻ってしまうことはありません
- スマホの「戻る」操作でも、ページから出ずに設定画面へ戻ります

### 読み上げ機能（VoiceOver / TalkBack）への配慮

- ふりがなを二重に読まない工夫をしています（「色いろ」ではなく「色」と読みます）
- 色の見本やボタンには、代わりの説明文（`aria-label`）を付けています
- 「黄色を 2 番目に追加しました」「青にしました」「点灯しました」など、操作の結果を読み上げます
- 点灯中も読み上げが届くよう、点灯画面の中に読み上げ用の場所を用意しています
- 見出しは「手順 1、光り方」のように、手順の番号が分かる形で読み上げます
- 点灯中は点灯画面だけを操作できるようにし、「戻る」ボタンに自動でフォーカスします
- 「点灯する」が押せないときは、その理由も読み上げます

### キーボード・スイッチ操作

| キー | 動き |
| --- | --- |
| `Esc` | パネルを閉じる／設定画面に戻る |
| `1`〜`9` | その色にする（1=赤 … 9=ピンク）。カラーチェンジの色選び中は、その色を加える／はずす |
| `↓` または `C` | 色を選ぶパネルを開く |
| `Tab` / `Enter` / `Space` | ボタンの移動と決定 |

- 端末で「視差効果を減らす」を設定している場合は、ボタンの動きを控えめにします

## 公開のしかた

### ファイル構成

7 つのファイルを、**同じフォルダのまま**公開してください。どれか 1 つでも欠けると、オフライン機能が働きません。

| ファイル | 役割 |
| --- | --- |
| `index.html` | ペンライト本体（書体も埋め込み済み） |
| `sw.js` | オフライン用の保存処理（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前やアイコンの設定 |
| `icon-180.png` | iPhone・iPad のホーム画面アイコン |
| `icon-192.png` | Android のホーム画面アイコン |
| `icon-512.png` | Android の起動画面・切り抜き用アイコン |
| `icon.svg` | パソコンのブラウザのタブに出る小さなアイコン |

### 公開する場所

オフライン機能は **https** のサイトでしか動きません。GitHub Pages や Netlify など、https で公開できる場所に置いてください。
（`index.html` をパソコンで直接開いても動きますが、オフライン機能は働きません）

### 中身を更新したとき

`sw.js` の `VERSION`（`penlight-v7` など）の数字を 1 つ上げてください。
上げないと、前の版を開いたことがあるスマホに古い保存分が残ることがあります。

更新した版は、スマホでページを**2 回目に開いたとき**に反映されます（1 回目は保存してある前の版がすぐ表示され、その間に新しい版を受け取ります）。

### 文字を書き足したとき

`index.html` に埋め込んだ書体は、ファイルサイズを小さくするため、**今ページで使っている文字だけ**を収めています。
新しい漢字などを書き足すと、その文字だけ端末に入っている書体で表示されます。書体をそろえたいときは、書体の埋め込みを作り直してください。

```sh
# 例：fontTools で、ページで使う文字だけの書体（woff2）を作る
pip install fonttools brotli
pyftsubset BIZUDPGothic-Bold.ttf --text-file=index.html --flavor=woff2 --output-file=bold.woff2
```

作った woff2 を base64 に変換し、`index.html` の先頭にある `@font-face` の `src` と入れ替えます（Regular と Bold の 2 つ）。

## イベント当日の運用

- **会場に入る前に一度開いてもらう** … 電波のある場所で一度開けば、会場で電波がなくても動きます。QR コードを事前に配る方法がおすすめです
- **ホーム画面への追加をすすめる** … 画面いっぱいで使えて、次から探さずに開けます
- **明るさは最大に** … 受付などで、口頭や紙でも伝えてください（画面の文字を読むのが難しい人もいるためです）
- **電池に余裕を** … 明るさ最大で長時間光らせると電池が大きく減ります。モバイルバッテリーがあると安心です
- **明るい屋外では目立ちにくい** … 日中の日なたでは、スマホの画面の光はあまり見えません。夕方以降や屋内のステージ向きです

## 動作環境

| 端末 | ブラウザ | 備考 |
| --- | --- | --- |
| iPhone | Safari（iOS 16.4 以降を推奨） | ブラウザのままでは全画面表示はできません。ホーム画面に追加して開くと画面いっぱいになります |
| Android | Chrome | 全画面表示とスリープ防止に対応 |

### できないこと・注意点

- **画面の明るさは自動で上げられません。** Web ブラウザが明るさの変更を許可していないためです。
  自動で最大にするには、ネイティブアプリにするか、[Capacitor](https://capacitorjs.com/) などでアプリ化して明るさ変更のプラグインを使う必要があります。
- **古い端末では、光っている間に画面が消えることがあります。** スリープ防止（Screen Wake Lock API）に対応していない端末です。スマホの自動ロックの時間を長くしてください。
- **カラーチェンジは、ほかの人のスマホとはそろいません。** それぞれ「点灯する」を押した時から動き始めます。
- **色の見え方には限界があります。** 緑が見分けにくいタイプの色覚の人には、黄色と黄緑はほぼ同じ色に見えます。そのため、色の名前を必ず表示しています。

## 使っている技術

- HTML / CSS / JavaScript（ライブラリなし）
- [Service Worker](https://developer.mozilla.org/ja/docs/Web/API/Service_Worker_API) … オフライン対応
- [Web App Manifest](https://developer.mozilla.org/ja/docs/Web/Manifest) … ホーム画面への追加
- [Screen Wake Lock API](https://developer.mozilla.org/ja/docs/Web/API/Screen_Wake_Lock_API) … 画面のスリープ防止
- [Fullscreen API](https://developer.mozilla.org/ja/docs/Web/API/Fullscreen_API) … 全画面表示
- [History API](https://developer.mozilla.org/ja/docs/Web/API/History_API) … スマホの「戻る」操作で設定画面に戻る
- `requestAnimationFrame` … 色のなめらかな変化
- `localStorage` … 選んだ色と光り方の保存
- [BIZ UDPGothic](https://fonts.google.com/specimen/BIZ+UDPGothic) … 使う文字だけを抜き出してページに埋め込み（[SIL Open Font License 1.1](https://openfontlicense.org/)）
